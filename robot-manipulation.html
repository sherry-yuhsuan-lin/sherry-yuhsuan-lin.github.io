Language-Guided Robotic Manipulation

Using a language model API to guide manipulation tasks in MuJoCo.

Demo video coming soon

Overview

This project connects visual perception with task planning and dynamic replanning in a simulated manipulation environment. It integrates YOLO-World for open-vocabulary object detection with LangGraph and a language model API.

Implementation highlights

  • Integrated object detection into a MuJoCo manipulation pipeline.
  • Connected visual observations with task planning and dynamic replanning.
  • Corrected a 2.7 cm sensor-calibration error to align visual perception with the simulated environment.
